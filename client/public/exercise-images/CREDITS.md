# Exercise images

The photos in this folder come from the
[Free Exercise DB](https://github.com/yuhonas/free-exercise-db), which is
released into the public domain under the
[Unlicense](https://unlicense.org/). No attribution is required; this note is
here so the source is easy to find.

Each `.webp` file joins the dataset's two photos for one exercise (start and
finish position) side by side, resized to 240px tall. The file names match the
image column in `server/src/seed.js`.

The YouTube tutorials are linked, not copied: the app stores only each video's
URL and opens it on youtube.com.
